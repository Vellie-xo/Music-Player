# 🎵 Custom Web Music Player

A sleek, modern web-based audio player interface built with semantic HTML5, CSS, FontAwesome icons, and Vanilla JavaScript.

---

## 📌 Features

* **Interactive Audio Controls:** Play and pause media dynamically using FontAwesome control icons.
* **Progress Slider:** Interactive `<input type="range">` track bar for monitoring song progress.
* **Modern Media Card Design:** Circular navigation buttons, song artwork display, and track metadata typography.
* **FontAwesome Integration:** Vector icon kit loaded via CDN for intuitive UI navigation and playback controls.
